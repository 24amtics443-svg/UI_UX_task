# 🕯️ Ankur — Ambient Lighting UI/UX Design

> **"Crafted to bring warmth and character into the space."**  
> An ultra-premium, dark-mode product landing page UI/UX concept designed in Figma for **Ankur** — a modern portable smart lantern engineered by Studio Ankur.

---

## 📌 Overview

**Ankur** is a luxury industrial-design and consumer-electronics landing page. The design embraces an **Obsidian & Champagne Gold** aesthetic, combining dark minimalist elegance, tactile physical product storytelling, and intuitive e-commerce conversion hierarchy.

* **Project**: Ankur Product Landing Page
* **Designer**: Aryan (Studio Ankur)
* **Design Tool**: Figma (`UI UX.fig`)
* **Design Philosophy**: Sculpting lighting that respects circadian rhythm and architectural craft.
* **Target Audience**: Architecture & interior design enthusiasts, minimalists, and luxury lifestyle consumers.

---

## 🎨 Design System & Visual Tokens

The Figma canvas is built on a structured design token system defined for typography, elevation, and color hierarchy:

### 🌈 Color Palette

| Token Name | Preview | Description / Usage |
| :--- | :---: | :--- |
| **Obsidian Dark** | `⬛ #0D0E12` | Deep canvas background for cinematic contrast |
| **Glass Surface** | `⬛ #17181F` | Subtle glassmorphic card backgrounds & overlays |
| **Champagne Gold** | `🟨 #E5C378` | Primary brand accent, interactive highlights, & CTA buttons |
| **Sunset Glow** | `🟧 #FFA347` | Ambient warm light ilAnkurnation & focal glow effects |
| **Primary White** | `⬜ #FFFFFF` | Main headlines, key statistics, and primary UI labels |
| **Muted Gray** | `▫️ #8E8E93` | Secondary text, specifications labels, and subtle borders |

### 🔤 Typography

* **Display & Headings**: `Urbanist` (Light, Regular, Semi-Bold)
  * Geometric modern typography with warm architectural clarity.
* **Body & Interface**: `Inter` (Regular, Medium, Bold)
  * Highly legible, crisp UI font for metadata, specifications, and navigation.

## 🚀 How to Open and Inspect the Design

### In Figma (Desktop App or Web)
1. Open [Figma](https://www.figma.com/).
2. In your Figma workspace or Drafts folder, click **Import file** (`.fig`).
3. Select `UI UX.fig` from this folder.
4. Open the imported canvas to inspect:
   * **Color Styles & Tokens**: View Obsidian Dark, Glass Surface, Champagne Gold, etc.
   * **Text Styles**: Urbanist & Inter font hierarchies.
   * **Components & Auto-Layout**: Responsive layout grids, cards, and CTA components.

### Required Free Fonts
Ensure you have the following Google Fonts installed on your system if editing text layers:
* [Urbanist (Google Fonts)](https://fonts.google.com/specimen/Urbanist)
* [Inter (Google Fonts)](https://fonts.google.com/specimen/Inter)
